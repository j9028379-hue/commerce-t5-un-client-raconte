# T5 · Référence de production
Le dépôt GitHub dédié contient le parcours, les 4 extraits CC BY, la source vidéo de démonstration (crédits : render/demo/plans.json), la voix, le moteur, la rotation, les tests et le Worker de référence en lecture seule. Drive est destiné aux copies de visionnage et non au versionnement. Les secrets de téléchargement de musique ne sont plus utilisés. Le workflow `sonore.yml` contrôle les quatre mixes, le parcours marchand, la parité des images, le manifeste, le Worker et la rotation. La confirmation de livraison est isolée du rendu ; historique durable sur state/commerce-autoplay. Cloudflare non déployé en production. Le contrôle historique du film Pixabay est disponible dans la release architecture-t5-v1.0.0.
